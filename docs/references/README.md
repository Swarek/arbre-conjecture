# Reference Documents

These local copies preserve the research material used to orient the PC-tree /
circular Robinson investigation. They are source material only: claims from
these documents must still be restated as explicit lemmas, conjectures, or
experimental hypotheses in the track documents before they are used by an
algorithm.

## Files

- `strongly-circular-sidma-1.pdf`: circular and strongly circular Robinson
  background.
- `Robinson_modules-1.pdf`: Robinson modules background.
- `PC-Trees_vs._PQ-Trees__Hsu-2.pdf`: PC-tree versus PQ-tree reference.
- `Modules_PQ-tree-1.pdf`: module and PQ-tree reference.
- `Hsu-McConnel_PC-trees-1.pdf`: Hsu/McConnell PC-tree reference.
- `Brucker_Osswald-1.pdf`: additional Robinson/quasi-circular reference.
- `proposition_4_4_farthest_crossing.png`: captured statement of Proposition
  4.4 on farthest-neighbor crossing constraints.
