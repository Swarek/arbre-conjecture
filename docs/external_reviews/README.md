# External Reviews

Ce dossier conserve les analyses externes utilisees pour orienter la recherche.
Elles ne sont pas des preuves internes : toute affirmation utile doit etre
reformulee en lemme, experience falsifiable, test de regression ou obligation
dans les documents du depot.

Regles :

- ne jamais remplacer un test ou une preuve par une revue externe ;
- separer les pistes globales des recommandations ancrees sur le dernier
  checkpoint ;
- transformer chaque idee retenue en artefact : doc de piste, test, generateur,
  contre-exemple ou obligation de preuve.

- `gpt55_global_strategy_2026-05-23.md` : revue globale post-T057, reroutee
  vers plusieurs pistes.
- `gpt55_global_strategy_addendum_2026-05-23.md` : rappel que la revue ne doit
  pas enfermer le Goal dans T056/T057 ; elle liste les experiences a garder
  separees.
- `researcher_advances_2026-05-31.md` : triage des notes externes et du
  screenshot manuscrit fournis le 2026-05-31. A lire comme portefeuille
  d'hypotheses falsifiables : interface P-noeud, largeur 4 conditionnelle,
  projection bad-side complete et route circle graph.
