# External Reviews

Ce dossier conserve les analyses externes utilisees pour orienter la recherche.
Elles ne sont pas des preuves internes : toute affirmation utile doit etre
reformulee en lemme, experience falsifiable, test de regression ou obligation
dans les documents du depot.

Regles :

- ne jamais remplacer un test ou une preuve par une revue externe ;
- separer les pistes globales des recommandations ancrees sur le dernier
  checkpoint ;
- transformer chaque idee retenue en artefact : doc de piste, test, generateur,
  contre-exemple ou obligation de preuve.
